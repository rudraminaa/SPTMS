# Changelog

All notable changes to this project are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-15

### Added
- Interactive Three.js parking facility and 2D floorplan.
- Bay reservation, check-in, walk-in, release and traffic simulation workflows.
- Express REST API and WebSocket state synchronization.
- Occupancy, revenue, projection and demand-heatmap analytics.
- Shared parking-domain logic and automated unit tests.
- GitHub-ready project documentation, contribution guidance, security policy and MIT license.

### Notes
- Initial documented project release; facility state is held in memory and resets on server restart.
